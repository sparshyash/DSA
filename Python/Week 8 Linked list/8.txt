A linked list is a linear data structure in which elements, called nodes, are stored at non-contiguous memory locations, each node having data and a pointer (next or prev or both).

Types of Linked Lists

Singly Linked List (SLL): Each node stores data + pointer to next.

Linked List Node Structure


class Node:
    def __init__(self, val):
        self.data = val
        self.next = None


__init__ is the constructor method in Python. It is called automatically whenever you create a new object (instance) of a class, and it is used to set up (initialize) the object's starting attributes.

In this specific Node class context, here is what each part does:

self: Represents the specific instance of the Node being created.

val: An argument passed in when creating the node (e.g., Node(10) passes 10 as val).

self.data = val: Creates an attribute named data on the node and assigns the passed value to it.

self.next = None: Creates an attribute named next and sets it to None by default, because a newly created node doesn't point to any other node yet.

def createList(arr):
   
    if not arr: 
        return None
    head = Node(arr[0])
    curr = head
   
    for i in arr[1:]:
        curr.next = Node(i)
        curr = curr.next
    return head
